#+TITLE: 08 — register machine (controller as FSM)
#+STARTUP: showall
* Difficulty
7 / 8 — a controller state machine over a datapath.
* Provenance
Abelson & Sussman, /SICP/ §5.1 (GCD, factorial).
* The machine
- A *controller* = labelled instruction points (states) with =test/branch/goto=
  transitions, over a *datapath* of registers + operations (and a stack for
  recursion).
- GCD: =test-b → (b=0? done) → t←rem(a,b); a←b; b←t; goto test-b= (a *loop*).
- Factorial: base test, push/pop stack around the recursive call (multiple
  entry/exit via saved =continue=).
* What to implement
Fold an execution trace (instruction log + register writes) into the final
register state; report illegal jumps, reads of uninitialized registers, and
stack imbalance. The projection is the register file at =done=.
* The lesson
"States = labelled instruction points; transitions = branch/goto; state data =
register contents." Iterative = a loop; recursive = a loop + a stack. The
controller is a finite state machine; the datapath makes it Turing-powerful.
